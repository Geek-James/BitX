## 🎯 核心功能

### 1. 技术指标系统
**功能描述**: 完整的技术分析指标系统

**包含指标**:
- MA均线（5/10/20/30周期）
- EMA指数移动平均线
- BOLL布林带
- MACD（DIF/DEA/柱状图）
- RSI相对强弱指标
- KDJ随机指标

**特点**:
- 指标计算准确，经过单元测试验证
- 支持主图和副图分离显示
- 可自由选择和切换指标
- 实时计算和更新

### 2. 实时更新系统
**功能描述**: WebSocket实时K线数据推送和更新

**核心功能**:
- WebSocket K线订阅
- 实时数据推送
- 智能数据合并（更新最后一根或添加新K线）
- 防抖优化（100ms）
- 自动订阅管理
- 完善的生命周期管理

**特点**:
- 更新延迟<100ms（目标<500ms）
- 无内存泄漏
- 自动重连机制
- 智能判断K线更新逻辑

### 3. 主题系统
**功能描述**: 完全可自定义的图表配色方案

### 4. 多图表对比
**功能描述**: 同时查看多个交易对的K线图表

**布局类型**:
1. **单图模式**: 专注单一交易对
2. **垂直2分屏**: 上下对比两个交易对
3. **水平2分屏**: 左右对比两个交易对
4. **2x2网格**: 同时查看4个交易对

**核心功能**:
- 独立交易对选择
- 独立时间周期切换
- 时间周期同步（可选）
- 缩放同步（可选）
- 点击跳转详情页

**特点**:
- 灵活的布局切换
- 迷你K线图组件
- 实时价格显示
- 涨跌幅显示
- 响应式设计

## 🎨 用户体验

### 操作流程

1. **查看K线图**
   - 进入市场详情页
   - 自动加载历史K线数据
   - 实时接收最新数据更新

2. **切换技术指标**
   - 点击指标按钮（图表图标）
   - 选择主图指标（可多选）
   - 选择副图指标（单选）
   - 立即生效，实时计算

3. **自定义主题**
   - 点击主题按钮（调色板图标）
   - 选择预设主题或自定义颜色
   - 实时预览效果
   - 自动保存设置

4. **切换时间周期**
   - 点击时间周期选择器
   - 选择不同周期（1m/5m/15m/30m/1h/4h/1d/1w）
   - 自动重新订阅和加载数据

5. **多图表对比**
   - 点击多图表对比按钮
   - 选择布局类型（单图/2分屏/4网格）
   - 为每个图表选择交易对和周期
   - 启用同步功能（可选）
   - 点击图表跳转到详情页

    ↓
KlineDataNotifier
    ↓ (防抖 + 数据合并)
KlineDataState
    ↓
klineDataListProvider
    ↓
┌─────────────────┬──────────────────┬──────────────────┐
│                 │                  │                  │
KlineChart    IndicatorProvider   SubCharts      ThemeProvider
(主图)         (计算指标)         (副图)          (应用主题)

## 🎓 技术总结

### 成功经验

1. **模块化设计**: 每个功能独立封装，易于维护和扩展
2. **测试驱动**: 先写测试，保证代码质量
3. **渐进式开发**: 从核心功能开始，逐步完善
4. **用户导向**: 关注用户体验，优化交互流程

### 技术选型

1. **Riverpod**: 强大的状态管理，自动管理生命周期
2. **CustomPainter**: 高性能图表绘制
3. **SharedPreferences**: 简单可靠的本地存储
4. **WebSocket**: 实时数据推送

### 最佳实践

1. **防抖优化**: 避免过于频繁的UI更新
2. **数据限制**: 防止内存溢出
3. **自动清理**: 避免内存泄漏
4. **响应式布局**: 适配不同屏幕尺寸
