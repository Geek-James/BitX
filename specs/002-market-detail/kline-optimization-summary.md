## 技术架构

### 核心组件

```
mobile/lib/features/markets/
├── models/
│   ├── indicator_config.dart          # 指标配置模型
│   ├── kline_data.dart                # K线数据模型
│   └── kline_interval.dart            # 时间周期枚举
├── utils/
│   └── indicator_calculator.dart      # 指标计算器
├── providers/
│   ├── market_detail_provider.dart    # K线数据Provider（实时更新）
│   └── indicator_provider.dart        # 指标Provider
├── widgets/
│   ├── kline_chart.dart              # K线主图
│   ├── macd_chart.dart               # MACD副图
│   ├── rsi_chart.dart                # RSI副图
│   ├── kdj_chart.dart                # KDJ副图
│   ├── sub_chart_container.dart      # 副图容器
│   └── indicator_selector.dart       # 指标选择器
└── screens/
    └── market_detail_screen.dart     # 详情页面

mobile/lib/shared/network/
└── websocket_service.dart            # WebSocket服务（扩展）
```

### 数据流

```
WebSocket Server
    ↓ (实时K线数据)
WebSocketService.klineStream
    ↓
KlineDataNotifier
    ↓ (防抖 + 数据合并)
KlineDataState
    ↓
klineDataListProvider
    ↓
┌─────────────────┬──────────────────┐
│                 │                  │
KlineChart    IndicatorProvider   SubCharts
(主图)         (计算指标)         (副图)
```
