# 价格一致性优化 - 修复总结

## 修复时间
2026-02-22

## 一、问题描述

用户反馈：行情列表显示的价格和行情详情页面（K线图、订单薄、深度图、最新成交）的价格差距太大，数据不一致。

### 问题原因分析

1. **历史K线生成问题**
   - 生成200根K线时，每根K线波动1%
   - 累计波动导致最终价格偏离初始价格很远
   - 例如：初始50000 → 200根K线后变成45000或55000

2. **价格更新幅度过大**
   - 使用`updatePrice()`方法，每次波动0.05%
   - 频繁调用导致价格快速偏离
   - 订单薄价差0.01%-0.05%，相对较大

3. **缺乏价格回归机制**
   - 价格一旦偏离，无法自动回归
   - 不同模块的价格各自演化

## 二、修复方案

### 2.1 优化历史K线生成

**修复前**：
```dart
// 每根K线波动1%，累计偏离严重
final volatility = 0.01;
final change = random * price * volatility;
price = price + change; // 价格持续偏离
```

**修复后**：
```dart
// 1. 保存目标价格
final targetPrice = state.currentPrice;

// 2. 起始价格在目标价格的95%-105%范围
double price = targetPrice * (0.95 + random * 0.1);

// 3. 使用更小的波动率（0.3%）
final volatility = 0.003;

// 4. 最后10根K线逐渐回归目标价格
if (i < 10) {
  final progress = (10 - i) / 10.0;
  final targetChange = (targetPrice - price) * progress * 0.3;
  close = price + targetChange + randomChange;
}

// 5. 确保最后一根K线收盘价接近目标价格（误差<1%）
if (diffPercent > 0.01) {
  adjustedKline.close = targetPrice;
}
```

**效果**：
- ✅ 历史K线价格围绕当前价格波动
- ✅ 最后一根K线收盘价 = 当前价格（误差<1%）
- ✅ 避免价格大幅偏离

### 2.2 优化实时价格更新

**修复前**：
```dart
// 使用updatePrice()，波动0.05%
final price = updatePrice(symbol);
// 每次调用都会累积偏离
```

**修复后**：
```dart
// 在当前价格附近小幅波动（±0.02%）
final currentPrice = state.currentPrice;
final priceVariation = currentPrice * 0.0002;
final price = currentPrice + (random - 0.5) * 2 * priceVariation;

// 更新价格状态
state.currentPrice = price;
```

**效果**：
- ✅ 价格波动幅度从0.05%降低到0.02%
- ✅ 价格变化更平滑
- ✅ 避免快速偏离

### 2.3 优化订单薄价差

**修复前**：
```dart
// 价差0.01%-0.05%
final spreadPercent = 0.0001 + random * 0.0004;
```

**修复后**：
```dart
// 价差0.01%-0.03%（更小）
final spreadPercent = 0.0001 + random * 0.0002;
```

**效果**：
- ✅ 订单薄中间价更接近当前价格
- ✅ 买卖价差更合理

### 2.4 优化24小时高低价

**修复前**：
```dart
// 高低价可能偏离当前价格很远
final high24h = recentPrices.max * (1 + random * 0.01);
final low24h = recentPrices.min * (1 - random * 0.01);
```

**修复后**：
```dart
// 1. 限制高低价在当前价格的±3%范围
high24h = min(high24h, currentPrice * 1.03);
low24h = max(low24h, currentPrice * 0.97);

// 2. 确保当前价格在高低价之间
if (currentPrice > high24h) high24h = currentPrice;
if (currentPrice < low24h) low24h = currentPrice;

// 3. 如果历史数据不足，使用±1.5%
high24h = currentPrice * (1 + random * 0.015);
low24h = currentPrice * (1 - random * 0.015);
```

**效果**：
- ✅ 24小时高低价更合理
- ✅ 当前价格始终在高低价之间
- ✅ 避免出现异常数据

## 四、技术细节

### 4.1 价格回归算法

```dart
// 最后10根K线逐渐回归目标价格
if (i < 10) {
  final progress = (10 - i) / 10.0;  // 0.1 → 1.0
  final targetChange = (targetPrice - price) * progress * 0.3;
  close = price + targetChange + randomChange;
}
```

**原理**：
- 最后10根K线，逐渐增加向目标价格靠拢的力度
- progress从0.1增加到1.0
- 每根K线向目标价格移动30%的差距
- 同时保留随机波动，保持自然

### 4.2 价格微调机制

```dart
// 在当前价格附近±0.02%波动
final priceVariation = currentPrice * 0.0002;
final price = currentPrice + (random - 0.5) * 2 * priceVariation;
```

**原理**：
- 波动范围：currentPrice * (1 ± 0.0002)
- 例如：50000 → 49990 ~ 50010
- 保持价格稳定，避免大幅跳变

### 4.3 价格边界保护

```dart
// 确保当前价格在24小时高低价之间
if (currentPrice > high24h) high24h = currentPrice;
if (currentPrice < low24h) low24h = currentPrice;

// 限制高低价在合理范围
high24h = min(high24h, currentPrice * 1.03);
low24h = max(low24h, currentPrice * 0.97);
```

**原理**：
- 防止出现逻辑错误（当前价格超出高低价）
- 限制高低价在±3%范围内
- 保证数据合理性
