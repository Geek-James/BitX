# K线图表手势操作说明

## 支持的手势

### 1. 双指缩放 (Pinch to Zoom)
- **操作**: 两根手指同时触摸屏幕,向外拉伸放大,向内收缩缩小
- **效果**: 调整K线图表的时间范围,查看更多或更少的K线数据
- **用途**: 
  - 放大: 查看更细节的价格波动
  - 缩小: 查看更长时间的价格趋势

### 2. 单指拖动 (Pan)
- **操作**: 单根手指触摸屏幕并左右滑动
- **效果**: 在时间轴上移动,查看历史数据
- **用途**: 
  - 向左滑动: 查看更早的历史数据
  - 向右滑动: 回到最新数据

### 3. 长按 (Long Press)
- **操作**: 长按图表任意位置
- **效果**: 显示十字线和该时间点的详细数据
- **显示信息**:
  - 时间
  - 开盘价 (Open)
  - 收盘价 (Close)
  - 最高价 (High)
  - 最低价 (Low)
  - 成交量 (Volume)

## 技术实现

### 使用的库
- **candlesticks**: 专为加密货币交易设计的K线图表库
- **版本**: 2.1.0
- **特点**: 
  - 内置手势支持,无需额外配置
  - 流畅的动画效果
  - 自动处理缩放和拖动边界
  - 支持自定义样式

### 数据格式
```dart
Candle(
  date: DateTime,      // 时间戳
  open: double,        // 开盘价
  high: double,        // 最高价
  low: double,         // 最低价
  close: double,       // 收盘价
  volume: double,      // 成交量
)
```

### 时间周期
- 1分钟 (1m)
- 5分钟 (5m)
- 15分钟 (15m)
- 30分钟 (30m)
- 1小时 (1h)
- 4小时 (4h)
- 1天 (1d)

## 性能优化

1. **数据量控制**: 每次加载100个数据点,避免一次性加载过多数据
2. **懒加载**: 支持滑动到边界时自动加载更多历史数据
3. **状态管理**: 使用 Riverpod 管理数据状态,避免重复请求
4. **缓存机制**: 切换时间周期时缓存已加载的数据

## 用户体验

1. **加载状态**: 显示加载动画,提示用户数据正在加载
2. **空状态**: 当没有数据时显示友好的提示信息
3. **错误处理**: 网络错误时显示错误信息和重试按钮
4. **流畅动画**: 所有交互都有平滑的动画过渡

## 未来优化方向

1. **指标叠加**: 支持添加MA、MACD、RSI等技术指标
2. **画线工具**: 支持用户在图表上画趋势线、水平线等
3. **多图表对比**: 支持同时查看多个交易对的K线图
4. **自定义配色**: 支持用户自定义涨跌颜色和主题
5. **实时更新**: WebSocket 实时推送最新K线数据
