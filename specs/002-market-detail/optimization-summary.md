## 三、技术实现要点

### 3.1 统一价格管理

```dart
class _PriceState {
  double currentPrice;           // 当前价格
  List<double> priceHistory;     // 价格历史
  int trendDirection;            // 趋势方向 (1=上涨, -1=下跌)
  int trendCounter;              // 趋势计数器
}
```

每个交易对维护独立的价格状态，确保价格变化的连续性和趋势性。

### 3.2 价格更新算法

- **基础波动**: 0.05%
- **时间因子**: 更新间隔越长，波动越大（最大5倍）
- **趋势影响**: 30%的方向性，每10次更新后随机切换
- **价格连续性**: 基于上一次价格计算变化

### 3.3 数据生成顺序

```
1. 生成交易记录 → 更新价格
2. 生成订单薄 → 基于最新价格
3. 更新K线 → 基于最新价格
4. 更新行情列表 → 基于价格历史
```

### 3.4 数据关联特性

- **订单薄中间价 = 当前价格**（±0.01%-0.05%价差）
- **成交记录价格 = 当前价格**（触发价格更新）
- **K线收盘价 = 当前价格**
- **行情列表最新价 = 当前价格**
- **成交量与价格波动相关**
- **买卖方向与价格趋势相关**

### 4.3 真实性

✅ **优化前**: 数据看起来是随机生成的  
✅ **优化后**: 数据有关联性，模拟真实市场行为

- 内存占用: 稳定（价格历史限制1000条）
- CPU占用: 低（防抖优化）
