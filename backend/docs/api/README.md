# CybitX API 契约文档

本目录包含 CybitX 前后端协作的 API 契约文档。

## 文档结构

- `restful-api.md` - RESTful API 规范（或使用 OpenAPI/Swagger YAML）
- `websocket.md` - WebSocket 实时通信规范
- `error-codes.md` - 统一错误码定义
- `data-models.md` - 数据模型定义

## RESTful API

用于请求-响应模式的业务操作：
- 用户登录/注册
- 下单、平仓
- 充提币申请
- 账户设置修改
- 历史数据查询

**文档格式**：推荐使用 OpenAPI 3.0 规范（Swagger）

## WebSocket

用于实时数据流推送：
- 行情数据（实时价格、深度、成交记录）
- K线图数据（实时更新与历史订阅）
- 跟单数据（信号、订单状态、收益更新）
- 订单与仓位更新（状态变更、持仓变动、资产余额）

**文档格式**：详见 `websocket.md`

## 契约变更流程

1. 任何 API 变更（新增接口、修改参数、调整错误码等）**必须**先更新契约文档
2. 在功能规格或实现计划中说明对移动端的影响
3. 后端提供契约测试（Contract Tests），确保实际接口行为与文档一致
4. 移动端基于契约编写集成测试，验证与后端的协作正确性

## 版本管理

契约文档遵循语义化版本：
- **主版本（X.0.0）**：不向后兼容的破坏性变更
- **次版本（0.Y.0）**：新增功能，向后兼容
- **补丁版本（0.0.Z）**：错误修复，向后兼容
